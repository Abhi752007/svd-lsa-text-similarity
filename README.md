# SVD-Based Latent Semantic Analysis for Text Document Similarity

Academic project implementing Latent Semantic Analysis (LSA) using Singular Value Decomposition (SVD) to identify similarity between text documents.

## Pipeline

Documents
→ Preprocessing
→ TF-IDF Matrix
→ SVD
→ Reduced Latent Semantic Space
→ Cosine Similarity
→ Ranked Similar Documents
